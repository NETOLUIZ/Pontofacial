# Diretrizes do Projeto

## Modo de Execução Direta e Autônomo
- Não faça perguntas clarificadoras, entrevistas ou questionários antes de começar a trabalhar.
- Tome decisões sensatas e adote as melhores práticas de arquitetura e código diretamente.
- Vá direto para a implementação, criação de arquivos e execução de testes.
- Não use brainstorming para travar a execução com perguntas; execute autonomamente.
- Apenas pare para perguntar em casos de risco real de perda de dados irreversível.
